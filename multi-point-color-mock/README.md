# 多点取色背景图mock工具

上传图片，从媒体边缘的 12 个采样点生成柔雾背景。图片仅在浏览器处理，无需构建或服务器。

## 使用

将此目录放入 GitHub Pages 已发布的分支目录内，通过 `multi-point-color-mock/index.html` 访问。

默认输出 940 × 668 PNG；“导出 PNG”仅输出背景，不含原图、文字界面或取色点。

## 固定参数

- 竖图左右各 6 点；横图上下各 6 点，自动判断
- 柔雾扩散：24%
- OKLCH 亮度 L：0.28–0.50
- 色度上限 C：0.12
- 沿边端点内缩：2%
- 向内取色偏移：2 px
- 单点取样：1 × 1 px

12 点采样后约束 OKLCH，在 OKLab 中按空间高斯权重平滑混合，再生成完整背景。保留原图的合成效果仅用于预览。支持原图扩展与已有黑边模式。

参考资料未提供完整 Shader 或具体参数；以上为已确认的固定参数，不能保证与参考 Demo 逐像素一致。

## 文件

- `index.html`：界面
- `style.css`：样式
- `app.js`：上传、预览与导出
- `engine.js`：取色及背景算法
- `demo.png`：示例图片
